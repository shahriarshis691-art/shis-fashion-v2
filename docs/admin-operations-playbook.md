# SHIS FASHION2 Admin Operations Playbook

This guide is for non-technical team members who manage products, homepage content, categories, and order flow.

## 1) Daily checklist (start of day)

1. Open Admin Dashboard.
2. Click **View New Orders** from dashboard summary.
3. Confirm each order and review customer details.
4. Update product stock for any fast-moving items.
5. Verify homepage sections are correct for current campaign.
6. Save any homepage changes before leaving.

## 2) Category management

Use this when creating new catalog groups.

1. Go to **Categories**.
2. Enter category name and click **Add**.
3. To rename, click **Edit** then **Update**.
4. To hide from active use, click **Delete** (archives only).
5. To recover by mistake, use **Archive center > Categories > Restore**.

Best practice:
- Add categories before creating products so product entry is faster.

## 3) Product and media management

Use this for new drops, restocks, and campaign refreshes.

1. Go to **Product CRUD**.
2. Fill: name, price, stock, category, description.
3. Add sizes/colors (comma separated).
4. Upload gallery images:
   - Main image
   - Detail image
   - Close-up image
5. Optionally upload product videos.
6. Toggle tags if needed:
   - Featured
   - New arrival
   - Hero spotlight
7. Click **Create product** (or **Update product** if editing).

Media tips:
- Keep image quality high and consistent.
- Remove wrong uploads immediately using **Remove** beside image/video.
- Keep stock accurate to avoid failed purchases.

## 4) Homepage section on/off control

Use this to control what customers see first.

1. Go to **Homepage**.
2. In **Homepage structure**, switch each section:
   - **Visible** = shown live
   - **Hidden** = not shown
3. Use **Up/Down** to reorder sections.
4. Update hero text/images/videos as needed.
5. Click **Save content**.

Important:
- Changes are not published until **Save content** is clicked.

## 5) Order status pipeline

Follow this order lifecycle exactly:

- New -> Confirmed -> Processing -> Shipped -> Delivered
- Cancelled can happen before delivery when needed.

How to process:
1. Open **Orders**.
2. Filter by pipeline buttons (New, Confirmed, Processing, Shipped, Delivered, Cancelled).
3. For each order, use **Mark ...** action buttons (safe next step only).
4. Add tracking number when shipped.
5. Click **Save** after editing customer/address/notes.

Do not skip steps.
- The dashboard blocks invalid transitions to keep workflow clean.

## 6) Archive and restore operations

Archived items are not permanently removed.

1. Go to **Categories > Archive center**.
2. Restore product/order/category from corresponding column.

Use restore when:
- Product was archived by mistake.
- Order needs to return to active management.
- Category was removed accidentally.

## 7) Quick troubleshooting

- "I updated homepage but site did not change": click **Save content**.
- "Cannot move order status": use only the next allowed status button.
- "Product not visible": verify stock > 0 and product is not archived.
- "Category missing in product flow": add category in Categories section first.

## 8) Weekly quality checks

1. Review out-of-stock items.
2. Review cancelled order reasons in notes.
3. Clean old or incorrect media assets.
4. Ensure featured/homepage campaigns match current season.
